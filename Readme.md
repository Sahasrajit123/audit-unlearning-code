This folder contains the code for the paper "Auditing of Unlearning Algorithms". 

The certified_unlearning_noisy_finetuning, hessian-unlearning and rewind2delete consists of the code for CIFAR100 for model clipping, hessian based method and rewind to delete algorithm respectively.

All the shakespere runs are in folder shakeshpere_plays/

And the output perturbation and Newton based convex unleaning algorithms are in the other two respective folders itself.
